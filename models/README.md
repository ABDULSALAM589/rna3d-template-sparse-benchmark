# Model Integrations

Each subdirectory documents setup and inference details for one candidate model.

Candidate methods:

- RhoFold+
- NuFold
- DRfold
- DRfold2
- trRosettaRNA2
- RNAbpFlow
- Protenix

Do not copy third-party source code into this repository unless its license permits it and there is a clear reason to vendor it.

Prefer documenting:

- upstream repository
- exact commit
- environment
- required inputs
- preprocessing
- inference command
- output conversion
- known limitations
