# Notebooks

This directory contains reproducible notebooks for remote execution environments such as Google Colab and Kaggle.

Recommended naming:

```text
drfold2_colab.ipynb
rnabpflow_kaggle.ipynb
trrosettarna2_colab.ipynb
...
```

Each notebook should record the model version/commit, environment setup, data source, hardware, inference command, runtime, and output location.
