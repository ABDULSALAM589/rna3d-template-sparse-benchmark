# Environments

Store reproducible environment specifications here.

Recommended files as model setup progresses:

```text
rhofold.yml
nufold.yml
drfold.yml
drfold2.yml
trrosettarna2.yml
rnabpflow.yml
protenix.yml
```

For each environment, record:
- operating system
- Python version
- PyTorch version
- CUDA version
- major dependencies
- installation notes
- tested GPU
